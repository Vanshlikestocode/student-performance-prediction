# Student Performance Prediction

## Overview
A machine learning project that predicts student performance based on study hours and attendance using linear regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the model:
   python model.py

## Use Case
This project demonstrates predictive modeling concepts applicable to real-world scenarios such as performance forecasting and risk assessment.
